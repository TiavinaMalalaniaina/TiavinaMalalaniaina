## Projets

### NaturaLodge — Gestion hôtelière

Application FullStack pour gérer les réservations, les chambres, les clients, la facturation et les paiements d’un établissement hôtelier. Elle comprend aussi le suivi des revenus, des dépenses et des indicateurs financiers.

**React · TypeScript · Node.js · Express · Prisma · PostgreSQL · Docker**

[Voir le projet et les captures](https://tiavinamalalaniaina.github.io/portfolio/naturalodge.html) · [Essayer la démo](https://naturalodge.onrender.com)

### SPAT — Pilotage des activités portuaires

Projet de stage à la Société du Port à gestion autonome de Toamasina : tableaux de bord du trafic maritime, suivi des volumes conteneurisés en EVP et des touchées de navires. Le projet comprend un pipeline ELT avec Python pour l’extraction et le chargement, et dbt pour les transformations SQL.

**React · TypeScript · Material UI · Java · Spring Boot · PostgreSQL · Python · dbt · Docker**

[Voir l’étude de cas](https://tiavinamalalaniaina.github.io/portfolio/spat.html) — Captures avec données fictives ; code et données de l’entreprise privés.

### Asa’ko — Gestion des PME

Contribution pendant mon stage chez RNA Dev à une application web et mobile : gestion des tâches, des fournisseurs, des commandes et des opérations de caisse. Certaines opérations fonctionnent hors connexion avec un stockage local.

**Laravel · React · Ionic · MySQL · SQLite**
